# 🚀 My English Journey — منصة تعليم الإنجليزية للأطفال بالذكاء الاصطناعي والإدارة الشاملة عبر Telegram

منصة تعليمية احترافية متكاملة موجهة للأطفال من عمر 5 إلى 7 سنوات، تعتمد على منهج الصوتيات والتأسيس اللغوي المبكر (**Phonics & Early Literacy**)، مع نظام مستويات تفاعلي، ومدرس ذكاء اصطناعي لتحليل نطق الأطفال وتصحيح الأخطاء، ونظام تعلم تكيفي (**AI Adaptive Learning**) يولد تدريبات إضافية تلقائية للأصوات التي يخطئ فيها الطفل، مع **إدارة مركزية كاملة من خلال بوت Telegram** دون الحاجة للوحة ويب تقليدية.

---

## 🌟 ميزات المنصة الرئيسية

1. **إدارة حصرية وشاملة عبر بوت Telegram (15 قسماً رئيسياً):**
   - إدارة الطلاب (جدد، نشطون، موقوفون، بحث بالاسم ورقم الهاتف و Student ID).
   - إدارة المستويات الثمانية وفتح وقفل المستويات وتعديل مستوى الطالب يدوياً.
   - إدارة الواجبات، استقبال تسليمات الطلاب، والاستماع للتسجيلات وتصحيحها ورصد الدرجات.
   - مركز مدرس الذكاء الاصطناعي واستقبال تنبيهات الصعوبات النطقية (مثل ضعف متكرر في صوت SH).
   - اعتماد الخطط التدريبية وتعديلها وإرسال الملاحظات الفورية للطلاب وأولياء الأمور.
   - الإحصائيات والتقارير الشاملة ومعدلات إتقان المنهج.

2. **عزل وأمان حسابات الطلاب:**
   - تحقق صارم من الاسم الثلاثي للطفل (Tripartite Name Validation).
   - فحص وتدقيق رقم الهاتف ومنع تكرار الحسابات.
   - تشفير كلمات المرور وحماية الجلسات باستخدام JWT.
   - معرف فريد لكل طالب `Student ID` (مثال: `STU-2026-XXXX`).
   - عزل تام لبيانات الطلاب على مستوى الخادم.

3. **منهج Phonics المعتمد (8 مستويات متدرجة بدقة):**
   - **Level 1 – Letter Sounds:** أصوات الحروف (S, A, T, P, I, N) والكلمات (Sat, Sit, Tap, Pin, Tan, Pan) والكلمات البصرية (I, A, See).
   - **Level 2 – CVC Words:** تكوين الكلمات الثلاثية (M, D, G, O, C, K) والكلمات (Dog, Cat, Mat, Map, Cot, Kid) والكلمات البصرية (The, And, On).
   - **Level 3 – Short Vowels:** الحركات القصيرة (E, U, R, H, B, F) والكلمات (Bed, Red, Hen, Bug, Sun, Run, Pen, Hot).
   - **Level 4 – More Letter Sounds:** استكمال الحروف (L, J, V, W, X, Y, Z, Q) والكلمات (Box, Fox, Web, Jet, Van, Zip, Yes, Quiz).
   - **Level 5 – Digraphs:** الأصوات المركبة (SH, CH, TH) والكلمات (Ship, Shop, Chip, Chat, Thin, This).
   - **Level 6 – Advanced Phonics:** التراكيب الصوتية (CK, NG, EE, OO) والكلمات (Duck, Song, See, Tree, Moon, Food).
   - **Level 7 – Vowel Teams:** فرق الحركات (AI, OA, AR, OR) والكلمات (Rain, Train, Boat, Coat, Car, Star).
   - **Level 8 – Reading & Writing:** المراجعة الشاملة والقراءة والكتابة وتكوين الجمل والشهادة النهائية.

4. **نظام الصوتيات والنطق الأمريكي المتقن:**
   - توليد وتوفير نطق بشري عالي النقاء للهجة الأمريكية (American English Neural Voice) لكل حرف، صوت Phoneme، صوت مركب، كلمة، وجملة.

5. **مدرس النطق الذكي (AI Pronunciation Teacher):**
   - تسجيل صوت الطفل عبر الميكروفون المدمج.
   - فحص جودة ونقاء الصوت (كشف الصمت التام أو الضوضاء المحيطة وتوجيه الطفل بإيجابية لإعادة التسجيل دون ظلم درجاته).
   - تحليل صوتي حقيقي ومطابقة صوتية (Phoneme Alignment) لاكتشاف الأصوات الناقصة والمستبدلة والمتقنة.
   - تقييم من 100 مع تقديم ملاحظات تشجيعية للأطفال.

6. **نظام التعلم التكيفي الذكي (AI Adaptive Learning Teacher):**
   - متابعة تكرار الأخطاء على مستوى الصوت (مثال: تكرار الخطأ في صوت SH 3 مرات فأكثر).
   - إنشاء مسار تدريب شخصي مخصص للطفل يحتوي على 4 خطوات متدرجة (استماع، تمييز صوتي، تكرار الكلمات، جملة التحدي).
   - إرسال تنبيه تشخيصي فوري للمدرس عبر Telegram مع أزرار للاستماع والاعتماد.

7. **الواجبات والاختبارات التفاعلية:**
   - أسئلة الاستماع، التوصيل، اختيار الكلمة، عد الأصوات.
   - شرط نجاح افتراضي 80% لاجتياز المستوى وفتح المستوى التالي تلقائياً.
   - إرسال إشعارات تسليم الواجبات ونتائج الاختبارات إلى Telegram.

8. **نظام التحفيز والجوائز (Gamification):**
   - كؤوس XP، نجوم ذهبية ⭐، سلسلة أيام التعلم Streak 🔥، أوسمة إنجاز، وشهادات تخرج رقمية قابلة للطباعة.

9. **ربط حساب ولي الأمر عبر Telegram:**
   - توليد رمز مؤقت فريد من 6 أرقام صالح لـ 15 دقيقة داخل الموقع.
   - إرسال `/link <code>` للبوت لإتمام الربط الآمن فوراً.
   - الموقع يعمل بكفاءة تامة واستقلالية حتى لو كان البوت متوقفاً مؤقتاً.

## ⚡ التشغيل السريع محلياً (Local Development)

### 1. تشغيل Backend وقاعدة البيانات:
```powershell
# من مجلد المشروع الرئيسي:
cd backend

# تفعيل البيئة الافتراضية:
.\venv\Scripts\Activate.ps1

# بذر البيانات وإنشاء الجداول والمستويات الثمانية:
$env:PYTHONPATH="backend"
python -m app.seed_data

# تشغيل خادم FastAPI:
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
سيكون الـ API ولوحة توثيق Swagger متاحة على:
- `http://127.0.0.1:8000/docs`
- والواجهة الأمامية متاحة مباشرة على: `http://127.0.0.1:8000/`

### 2. تشغيل الواجهة الأمامية بشكل منفصل (Vite Dev Server):
```powershell
cd frontend
npm run dev
```
تفتح الواجهة على `http://localhost:3000` مع بروكسي تلقائي للـ Backend.

### 3. تشغيل بوت إدارة Telegram:
1. افتح تطبيق Telegram وابحث عن `@BotFather` وأنشئ بوتاً جديداً واحصل على `API Token`.
2. ضع التوكن في ملف `backend/.env`:
   ```env
   TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN_HERE"
   TELEGRAM_ADMIN_IDS="YOUR_TELEGRAM_USER_ID"
   ```
   *(يمكنك معرفة معرفك على Telegram عبر بوت `@userinfobot`)*.
3. شغل البوت:
   ```powershell
   $env:PYTHONPATH="backend"
   python bot/bot_main.py
   ```
4. افتح البوت واضغط `/start` لتظهر لك فوراً لوحة التحكم الشاملة ذات الـ 15 قسماً!

## 🌐 النشر على خادم VPS (Production Deployment)

### الطريقة الأولى: باستخدام Docker Compose (الأسهل والأسرع)
1. انسخ ملفات المشروع إلى السيرفر:
   ```bash
   git clone <REPO_URL> /var/www/english-journey
   cd /var/www/english-journey
   ```
2. عيّن متغيرات البيئة في `.env`:
   ```bash
   cp backend/.env.example .env
   nano .env
   ```
3. شغل جميع الخدمات (PostgreSQL, Backend, Telegram Bot, Nginx):
   ```bash
   docker compose up -d --build
   ```

### الطريقة الثانية: باستخدام Systemd و Nginx على Ubuntu/Debian VPS
1. ثبت المتطلبات الأساسية:
   ```bash
   sudo apt update && sudo apt install -y python3.11 python3.11-venv postgresql ffmpeg nginx git
   ```
2. أنشئ قاعدة بيانات PostgreSQL:
   ```bash
   sudo -u postgres psql
   CREATE DATABASE english_journey;
   CREATE USER english_user WITH PASSWORD 'YourSecurePassword2026';
   GRANT ALL PRIVILEGES ON DATABASE english_journey TO english_user;
   \q
   ```
3. انقل خدمات systemd:
   ```bash
   sudo cp deploy/english-backend.service /etc/systemd/system/
   sudo cp deploy/english-bot.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now english-backend english-bot
   ```
4. تفعيل Nginx وشهادة SSL المجانية:
   ```bash
   sudo cp nginx.conf /etc/nginx/sites-available/english-journey
   sudo ln -s /etc/nginx/sites-available/english-journey /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   sudo certbot --nginx -d yourdomain.com
   ```
